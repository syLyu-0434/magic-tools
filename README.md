# 🔮 瑜的神祕妙妙工具屋 (Yu's Mysterious Wonderful Toolhouse)</h1>

歡迎來到**瑜的神祕妙妙工具屋**。這是一個基於 GitHub Pages 構建的個人工具入口網，融合了賽博龐克 (Cyberpunk) 與魔法 (Magic) 的視覺風格，旨在存放各種「妙妙」的開發成果。

## 🌌 空間概覽

這不僅是一個網頁，更是一個充滿魔法能量的介面。

**核心特性**

* **全息粒子背景**：動態 Canvas 渲染的星塵網絡，會隨時間緩慢流動。

* **玻璃擬態 UI**：所有工具卡片皆採用透明磨砂玻璃質感，並具備 3D 傾斜視差效果。

* **故障藝術 (Glitch Effect)**：標題與重點文字具備不穩定的現實感特效。

* **全息側邊欄**：隱形魔法抽屜設計，提供無縫的導航體驗。

* **混沌模式**：一個不建議按下的按鈕，按下後將扭曲現實。
